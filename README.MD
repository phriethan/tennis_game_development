Tennis Game

A browser-based tennis game built using JavaScript and the HTML Canvas API. The player controls the left paddle using the mouse while the computer controls the right paddle.

Features
Mouse-controlled player paddle
Computer-controlled opponent
Ball and paddle collision detection
Dynamic ball direction based on where the paddle is hit
Score tracking
First player to reach 3 points wins
Winning screen with option to restart the game
Technologies
HTML
JavaScript
HTML Canvas API
How to Play
Open the HTML file in a web browser.
Move your mouse vertically over the game to control the left paddle.
Try to hit the ball past the computer-controlled paddle.
The first player to reach 3 points wins.
Click the canvas after the game ends to play again.

Game Logic

The game runs on a continuous update loop that handles movement and rendering.
The ball's vertical velocity is also adjusted by where it contacts the paddle, allowing the player to influence the ball's direction.

Project Background
This project was developed as a learning project in JavaScript and HTML Canvas to practice browser-based game development, event handling, collision detection, animation, and drawing with the Canvas API.
